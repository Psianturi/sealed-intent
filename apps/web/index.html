What is real and what is not

  • Real: the rules are the same code that runs live; 1Click dry quotes and their signatures; NEAR AI Cloud attestation verified on our machine (Intel DCAP, NVIDIA NRAS); function-call key behaviour confirmed on a local NEAR node.
  • Simulated in the official run: the chain (an in-memory ledger with NEP-141 rules), 1Click quotes (fixtures signed with a local key), the TEE opinion, custody. The victim is scripted and follows every message; there is no LLM in the loop.
  • Not done yet: OutLayer execution, a mainnet swap, TLS binding to the gateway attestation, isolation of the Sealed Intent host from the agent.
  • Will not be fixed by this project: a stolen key, a bug in a token contract, or a compromised Sealed Intent host. The Arena shows these as escapes on purpose.
