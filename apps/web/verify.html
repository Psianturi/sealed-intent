What is checked

  • Operator signature: ed25519 over the canonical JSON of the receipt. Any edit invalidates it.
  • Who signed: confirmed only if you paste the key the operator published. Without it, this page says the key is unknown.
  • Enclave signature: the signed text must equal model:sha256(request):sha256(response) and recover to the signing address. Simulated enclaves are labelled and never count as attested.
  • Hardware evidence: the Intel and NVIDIA checks happen at decision time and are listed in the receipt. This page shows that record; it does not repeat them.
  • Opened fields: an opened value must match its salted commitment.
